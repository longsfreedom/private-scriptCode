根目录作为仓库入口，将两个相对独立的工作域并列组织：config 子模块集中存放 PoE 自动化所需的分辨率、ROI、模板匹配等 JSON 配置；tools 子模块提供基于截图、模板匹配与 Tesseract OCR 的命令行调试工具，二者共同服务于 PoE 自动化主流程（尚未在根目录展开）；disaster_advice_agent.py 是独立脚本，通过 urllib 直接 POST 到 91weather 的 chat completions API，按固定 system prompt 输出结构化防灾建议，不依赖 config 或 tools。根级 README.md、technical.plan.md、development.status.md、AGENTS.md 等文档统一描述 PoE 项目的阶段目标、验收指标与行为约束（状态机驱动、超时重试、止损停机），作为跨子模块的需求契约。
